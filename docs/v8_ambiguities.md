# V8: ασάφειες της προδιαγραφής (Στάδιο Α)

Υλοποίηση: `v8_reference.py` (VERSION `v8ref-1.0`). Πηγή: μόνο το `specification.md`. Κάθε σημείο έχει ID `AMB-xx`, που εμφανίζεται και στα σχόλια του κώδικα. Στη στήλη «Επίπτωση στη σύγκριση» φαίνεται ποιες διαφορές γραμμή-γραμμή μπορεί να προκαλέσει η κάθε επιλογή.

## Τι δεν υλοποιήθηκε

- Η κάλυψη ανά μέρα και ώρα υπάρχει στο funnel (`raw_rows_per_hour`, `grid_rows_per_hour`).
- Το `build_meta.json` δεν γράφεται ως ξεχωριστό αρχείο. Οι εκδόσεις, τα sha256 εισόδου και εξόδου και το config είναι μέσα στο `funnel.json`.
- Τα `vx_sog`/`vy_sog` δεν γράφονται, γιατί προκύπτουν από sog/cog.

## Σημεία για να ελεγχθούν πρώτα στη σύγκριση

1. Πλήθος spikes ανά μέρα. Ο §8 δίνει διάμεσο 395/μέρα τον Μάρτιο και συνολικά 15,399 spikes / 1,801 τομές άλματος με ανοχή 0 m. Τα AMB-08 και AMB-09 είναι οι πιθανότερες πηγές διαφορών.
2. Γραμμές εξόδου: η αναφορά είναι 21,229,500 για όλο τον Μάρτιο. Αυτό επηρεάζεται από τα AMB-03, AMB-22, AMB-23 και AMB-26.
3. Σύνολο (mmsi, t). Οι διαφορές πρέπει να εντοπιστούν στα AMB-10 και AMB-22 (άκρα segments).
